Josi CE 0.1 is beta-quality software. Features may be incomplete, unavailable, delayed, inaccurate or changed without notice. Do not use Josi as the sole system for emergencies, safety, healthcare, legal, financial, compliance, access control or backups. Review AI output and consequential actions yourself.

Help and current features

Josi CE currently provides one self-hosted workspace; account roles, password recovery and MFA; conversations, tasks and approvals; contacts; personalization and memory; usage and cost limits; hosted or local model providers; Google and Microsoft connections; contact synchronization; operational mail; document storage, extraction, search and citations; Telegram, Slack, WhatsApp and Signal channels; backups, restore, export and diagnostics; optional telemetry; system checkups; an installable PWA; optional Voice Box; developer-service connections; and licensed Family BETA controls.

Administrators configure infrastructure under Admin. Members use their own accounts under Workspace. Every signed-in page has a persistent Help link back to this guide.

Family / Parental Controls BETA

BETA — do not trust or rely on these controls for a child's safety. They are experimental and may fail, be delayed or behave unexpectedly. They control only access to Josi. They do not lock a device, block other apps or websites, monitor location or actual screen time, contact emergency services, or replace active adult supervision and proven device-level controls. Verify important restrictions independently.

Use Admin → Parental controls (BETA) to activate or manage the publisher-issued licence. Use Workspace → Family (BETA) to create a new managed child account, set Josi-only schedules and message-minute limits, review usage and—through an explicit parent-child relationship—view that child's Josi conversations. The child sees who supervises the account, what can be seen, and parental access events.

Voice Box

Voice Box is an optional local speech service. The host operator must provision the guarded helper before the Admin install control can work. Browser microphone permission is required. Voice Box is not an emergency calling or recording service and should not be treated as one.

Backups and system checkup

Admin → Overview includes a system checkup and recommendations. It is a useful diagnostic snapshot, not continuous monitoring or a warranty that the system is safe. Backups exclude the installation master key: keep that key separately and test restores.

Josi CLI and one-line installer

The signed Josi CLI keeps Docker Compose as the only runtime while providing operator commands for installation, status, updates, backups, logs, rollback, uninstallation, diagnosis, and repair. Install the current verified Linux amd64 or arm64 release with:

curl -fsSL https://github.com/vaxman14/josi-ce-public/releases/download/v0.1.65/install.sh |
  sudo bash -s -- --version 0.1.65 --yes

The installer requires an explicit version and verifies its pinned verifier, the release's Sigstore workflow identity, and the signed SHA-256 manifest before installing anything. You can instead download and inspect the script first.

josi doctor backs up state, applies safe deterministic repairs, verifies the real postcondition, and rolls back repairs that regress readiness. Use josi doctor --check-only for a read-only audit or --dry-run for the exact repair plan. --yes does not authorize AI repair.

Use josi logs --since 30m, josi support bundle, or josi doctor --export-ai-context PATH to collect a bounded, structured, secret-redacted diagnostic bundle. After deterministic repair is exhausted, josi doctor --ai-repair --allow-ai can offer a separately approved local Codex or loopback Ollama investigation. The exact plan requires a second approval before any allowlisted change executes.

Complete CLI guide · Public installer provenance

Admin → Backups provides a persistent progress display and guided SMB/NFS setup. Enter the NAS address and share, authenticate, browse to a folder, and let the restricted storage controller manage the Docker mount. Off-site encryption is enabled by default; save its one-time recovery key away from the backup destination. “Change” preserves saved settings until Save succeeds, while removal is a separate confirmed action.

Integrations

Admin → Integrations groups code, deployment, data, monitoring, knowledge, and project-management connections. Custom API connects unsupported HTTPS REST services through an explicit endpoint allowlist. Credentials remain in the Master Vault; writes and deletes require approval.
