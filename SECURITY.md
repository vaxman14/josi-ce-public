# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Use this repository's **Security** tab and select **Report a vulnerability** to
send a private GitHub Security Advisory. Include affected versions, impact,
reproduction steps, and any suggested mitigation.

Response and fix timelines depend on severity and whether the report can be
reproduced; the Community Preview does not include a response-time SLA.

## Supported versions

During the Community Preview, security fixes target the current published
release only. Operators should update to the latest release before reporting a
problem that may already be fixed.

## Scope

Reports about Josi CE code and its published container images are in scope.
Vulnerabilities in third-party services, operator-managed infrastructure, or
modified downstream builds should be reported to their respective maintainers.
