# Community Preview support policy

Josi CE 0.1 is a community preview. It includes **no support entitlement, no
guaranteed response time, and no service-level agreement**.

## Where to ask

- Use the GitHub question form for setup questions and community help.
- Use the GitHub bug-report form for reproducible defects.
- Report security vulnerabilities privately as described in `SECURITY.md`.

Do not post API keys, passwords, tokens, private documents, database dumps, or
diagnostic bundles containing personal data in a public issue or discussion.

## What maintainers may do

Maintainers may reproduce, classify, close, or request more information on a
report. Replies are best-effort and may not arrive. Community answers are not
official support commitments.

## Supported release

During Community Preview, only the newest published `0.1.x` image is eligible
for bug triage. A report should include the exact image tag or digest, host OS,
CPU architecture, Docker version, Compose version, and redacted reproduction
steps.

## Boundaries

- No remote access is implied or granted by opening a report.
- No emergency, compliance, legal, data-recovery, or production-operations
  service is provided.
- Paid support is not currently offered.
- Maintainers cannot recover a lost `secrets/master.key`.

This policy may change before a stable release. Changes apply prospectively and
will be published in this repository.
